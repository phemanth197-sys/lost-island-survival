# Lost Island Survival

A small, playable vertical slice of the full game concept: a modern top-down survival adventure built as a browser game.

## Included in this slice

- One beach and small jungle zone
- One cave entrance and hidden relic
- One NPC (Juno, the fisherman)
- One animal (turtle)
- One enemy (jungle beast)
- Inventory system
- Three crafting recipes
- Campfire placement
- Hunger, thirst, stamina, and health systems
- Day/night cycle
- One quest and one treasure objective
- Basic combat and dodge
- Auto-save via localStorage

## How to run

1. Open a terminal in the project folder.
2. Run:

```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in a browser.

## Controls

- Move: `WASD` / Arrow keys
- Run: `Shift`
- Interact: `E`
- Attack: `Left click` or `J`
- Dodge: `Space`
- Place campfire: `1` then click on the ground
- Save: `M`

## Notes

This is intentionally designed as a vertical slice, not the full game. It gives the core feel of the larger project while keeping the code modular and easy to expand.

The project is original, built from scratch, and can be extended with additional regions, quests, NPCs, combat systems, and more advanced survival mechanics.
